# Profile maintenance

This repository is named `ankush29922`, matching the account, so its public root
README appears on the GitHub profile. It contains profile artwork and writing,
not private application code or a copy of the owner's resume.

## Updating it

- Edit `README.md` for biography, featured projects and skills.
- Edit `scripts/generate-art.py`, then run `python scripts/generate-art.py` to
  regenerate the original SVG artwork. The script needs only the Python standard
  library and does not use remote image services.
- Keep the banner's `picture` element: it supplies dark and light variants.
- Keep real project/download/setup links and badge verification links current.
- Describe AWS Academy as a training badge; it is not an AWS professional-level
  certification. The Oracle credential uses its actual issuer title.
- Historical project and hackathon details were supplied by the owner. Do not
  turn them into invented employment, national awards or unverified live demos.
- Do not add contact phone numbers, private source, user databases, credentials
  or the original PDF resume. Use the public LinkedIn link for contact.

The `build/` directory is local-only research, validation and rollback material.
It must remain ignored. No visitor trackers, external statistics-card service,
scheduled bot or private-repository token is needed for this profile.

## Native GitHub pins

The README already features LGgramTV and TYPXEN. For GitHub's separate native
Pinned section, use the profile's **Customize your pins**, select those two public
repositories, and save. That UI setting is independent of README content.
